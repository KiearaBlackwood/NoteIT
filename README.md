# NoteIT
- Developed a blogging platform that features user authentication, real-time posting, and dynamic content feeds.
- Used Python and Flask to handle backend logic for signups, logins, and post management.
- Designed a database using Amazon Web Services to store user credentials, profile information, and post replies.
- Integrated secure user authentication with validation for unique emails and non-blank credentials.
- Technologies: Python (Flask), JavaScript, AJAX (XMLHttpRequest), HTML5, CSS3, SQL/Dynamodb, AWS Database, PythonAnywhere
